# Scientific Paper Checklist

Based on Hoffman's "How to Write a Scientific Paper" and peer review best practices.

## Structure

### Abstract
- [ ] Contains: aims, methodology, main findings, conclusions
- [ ] Readable in under 1 minute
- [ ] No jargon requiring the full paper to understand
- [ ] States the new finding clearly

### Introduction
- [ ] Paragraph 1: General motivation and applications
- [ ] Paragraph 2: Literature review with crucial gap identified
- [ ] Paragraph 3: "Here we show..." (similar to abstract but more detail)
- [ ] Recent, authoritative references demonstrate currency

### Methods
- [ ] Sufficient detail for replication
- [ ] Control experiments specified
- [ ] Statistical methods justified
- [ ] Sample sizes and selection criteria clear

### Results
- [ ] Clearly describes what data shows
- [ ] References statistical analyses and significance
- [ ] No interpretation (save for Discussion)
- [ ] Figures referenced in logical order

### Discussion
- [ ] Evaluates how study adds to existing knowledge
- [ ] Addresses limitations
- [ ] No repetition of Results
- [ ] Connects back to gap identified in Introduction

### Conclusion
- [ ] Summarizes findings (no new information)
- [ ] States implications
- [ ] Evidence-based (no unsupported claims)

## Figures

### Format
- [ ] Vector format (PDF/EPS) for scalability
- [ ] Consistent font type (Arial preferred)
- [ ] Font size ≥ 6 in final published figure
- [ ] Built at target column width from start

### Labels and Legends
- [ ] All axes labeled with units
- [ ] Each plot has legend describing all symbols and lines
- [ ] Each image has accurate scale bar with number
- [ ] Colorbars have numerical values and units

### Captions
- [ ] Describes all sub-parts in order
- [ ] Every mark on figure explained (no mysterious arrows)
- [ ] Analysis steps clearly divulged
- [ ] Error bar origins explained
- [ ] Experimental conditions stated (temperature, field, etc.)

### Style (Tufte principles)
- [ ] Maximize data-ink ratio
- [ ] Maximize data density
- [ ] No chart-junk (hatching patterns, 3D effects)
- [ ] Avoid excessive colors
- [ ] No red-green combinations (colorblind accessibility)
- [ ] Words oriented horizontally when possible

## References

- [ ] Consistent citation style throughout
- [ ] All references have DOI for hyperlinking
- [ ] No duplicate entries (check for same paper, different keys)
- [ ] All authors listed (no "and others" truncation)
- [ ] Special characters in names formatted correctly
- [ ] Titles properly capitalized in BibTeX

## Style and Grammar

### Voice and Attribution
- [ ] Active voice used (distinguishes your work from citations)
- [ ] Clear who did what (you vs. prior work)

### Clarity
- [ ] Pronouns avoided ("that voltage signal" not "that")
- [ ] Adjectives used when any doubt ("the z modulation" not "the modulation")
- [ ] All acronyms defined at first use
- [ ] Total acronyms minimized (5-10 max)
- [ ] Words before acronym not capitalized ("scanning tunneling microscopy (STM)")

### Technical
- [ ] All equations numbered
- [ ] All symbols defined before or after equations
- [ ] Equations dimensionally correct
- [ ] All numbers have units
- [ ] Reasonable significant figures
- [ ] Consistent quantity reporting throughout

### Word Choice
- [ ] "Significantly" only for statistical significance
- [ ] "Successfully" deleted (let results speak)
- [ ] "Only" placed immediately before word it modifies
- [ ] "Its" (possessive) vs "it's" (contraction) correct
- [ ] "Fewer" (discrete) vs "less" (continuous) correct
- [ ] "Which" vs "that" used correctly

## Professional Integrity

- [ ] All contributors included as authors
- [ ] Prior work properly cited
- [ ] Data acquisition and analysis methods clearly described
- [ ] Image processing disclosed
- [ ] Collaborator contributions acknowledged
- [ ] No conflicts of interest undisclosed
