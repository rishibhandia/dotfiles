# Grant Proposal Checklist

Based on NSF/NIH guidelines, NIMH common mistakes, and reviewer feedback.

## NIH Review Criteria (2025 Framework)

NIH now uses three factors:
1. **Importance of the Research** - significance and innovation
2. **Rigor and Feasibility** - approach and methodology
3. **Expertise and Resources** - investigators and environment

## Specific Aims

- [ ] Clear focus and defined objectives
- [ ] Realistic scope (not overambitious)
- [ ] Aims don't hinge on success of prior aims
- [ ] Future research directions indicated
- [ ] Testable hypothesis clearly stated
- [ ] Can be understood by non-specialist

## Significance

- [ ] Compelling justification for the work
- [ ] Advances the field (not just incremental)
- [ ] Addresses genuine unmet need
- [ ] Explains why this problem matters now
- [ ] Connects to funder priorities (check strategic plans, NOSIs)

## Innovation

- [ ] Clearly explains what's novel
- [ ] Distinguishes from prior approaches
- [ ] Avoids "this has never been done" (usually false)

## Approach

### Methodology
- [ ] Hypothesis-driven with testable predictions
- [ ] Sufficient methodological detail for review
- [ ] Unproven techniques explained thoroughly
- [ ] Experimental controls specified
- [ ] Statistical power and sample size justified
- [ ] Directly tests central hypothesis (not just correlative)

### Feasibility
- [ ] Preliminary data demonstrates ability to do difficult experiments
- [ ] Data presented professionally (legends, statistics, calibrations)
- [ ] Each aim shown to be achievable

### Contingency
- [ ] Alternative approaches if primary fails
- [ ] Discussion of potential pitfalls
- [ ] Multiple angles to test hypothesis

### Timeline
- [ ] Realistic milestones with dates
- [ ] Minimum ~3 months per checkpoint
- [ ] Demonstrates understanding of research path

## Investigators

- [ ] Relevant expertise demonstrated through publications
- [ ] Recent productivity shown
- [ ] Collaborator letters of support obtained
- [ ] Senior team member included if needed (new PIs)
- [ ] Experience with proposed methods documented

## Environment

- [ ] Institutional support documented
- [ ] Necessary equipment and resources available
- [ ] Inter-institutional collaboration evidence (if applicable)

## Budget

- [ ] Modular format used when required
- [ ] Consortium budgets separate
- [ ] All items justified (no guessing or padding)
- [ ] Equipment costs ($5K+) explained
- [ ] Year-to-year changes explained
- [ ] No voluntary cost-sharing (NSF prohibits)

## Broader Impacts (NSF)

Must address separately:
- [ ] STEM workforce diversity
- [ ] Full participation of underrepresented groups
- [ ] STEM education improvement
- [ ] Public scientific literacy
- [ ] Partnerships with industry/government
- [ ] National security, economic competitiveness, or public welfare

## Writing Quality

- [ ] Plain language for diverse reviewers
- [ ] Jargon minimized or explained
- [ ] Diagrams and tables clarify Approach
- [ ] Figures have complete legends
- [ ] No misused words or obscure terms
- [ ] Follows all formatting guidelines exactly

## Common Mistakes to Avoid

### Scientific
- Proposal lacks significance
- No testable hypothesis
- Overambitious aims
- Aims depend on prior aims succeeding
- Weak or absent preliminary data
- Missing statistical justification
- No alternative approaches

### Compliance
- Not following guidelines (easiest to avoid, most common mistake)
- Wrong budget format
- Missing required sections
- Exceeding page limits

### Presentation
- Jargon that confuses non-specialists
- Vague claims and trendy language
- Dismissing prior work
- Inflated or unsupported promises

## Pre-Submission Checklist

- [ ] Read RFP/FOA carefully
- [ ] Contacted program officer for advice
- [ ] Had colleague review as mock reviewer
- [ ] Checked all formatting requirements
- [ ] Verified page limits
- [ ] Proofread PDF output
- [ ] All required sections complete
- [ ] All collaborator materials received
