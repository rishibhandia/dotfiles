# Red Flags in Scientific Writing

Phrases and patterns that signal problems to reviewers.

## Amplifiers (Delete These)

These words signal lack of confidence. Real facts stand on their own merit.

| Delete | Why |
|--------|-----|
| remarkably | Subjective amplifier |
| very | Rarely adds meaning |
| incredibly | Hyperbolic |
| enormously | Hyperbolic |
| successfully | Let results speak |
| unique | Rarely true |
| novel | Often overused |
| groundbreaking | Let reviewers decide |
| unprecedented | Usually false |

## Vague Claims (Replace with Specifics)

These phrases signal you haven't figured out your conclusion. Replace with 1-2 factual sentences stating your discovery.

| Vague Phrase | Problem | Fix |
|--------------|---------|-----|
| "pave the way" | What way? For what? | State what is now enabled |
| "shed light on" | What light? | State what is revealed |
| "provide insight into" | What insight? | State the specific insight |
| "unveil" | What exactly? | State what is shown |
| "open new avenues" | Which avenues? | State the specific directions |
| "has implications for" | What implications? | State them explicitly |

## Grant-Specific Red Flags

| Phrase | Problem |
|--------|---------|
| "We will eradicate..." | Unrealistic promise |
| "This has never been done" | Usually false; dismisses prior work |
| "Obviously..." | Dismissive of reader |
| "Hopefully..." | Vague expectation |
| "We believe..." (overused) | Weakens claims; state evidence instead |
| "It is well known that..." | Cite source or delete |

## Structural Red Flags

### In Abstracts
- No clear statement of findings
- Methods without results
- Claims without evidence
- Jargon requiring full paper to understand

### In Introductions
- No clear gap in knowledge identified
- "Here we show..." buried or missing
- Literature review without direction
- Dismissing prior work instead of building on it

### In Methods
- "Standard procedures were used" (no detail)
- Missing statistical justification
- No mention of controls
- Sample size not specified

### In Results
- Interpretation mixed with data presentation
- Figures not referenced in order
- Claims without statistical support
- "Data not shown"

### In Discussion
- Repeating Results section
- Overstating significance
- Ignoring limitations
- Unconnected to Introduction's gap

## Questions to Force Clarity

When reviewing, ask:

1. **What is the new fact about nature discovered?**
   - If you can't state it in one sentence, the paper isn't ready

2. **What do we know now that we didn't know before?**
   - Must be concrete and specific

3. **If this aim fails, what's the backup?**
   - For proposals: contingency required

4. **Can a non-specialist understand the main point?**
   - Accessibility is essential for diverse review panels

5. **Would I fund/accept this if I were the reviewer?**
   - Honest self-assessment

## The "And" Test for Commits and Claims

If your main claim needs "and" to describe it, you may be trying to do too much:

**Problematic:**
> We discovered X and developed Y and showed Z.

**Better:**
> Focus on the single most important finding.

## Formatting Red Flags

- Figures with unreadable fonts (< size 6)
- Missing scale bars or colorbars
- Red-green color schemes (colorblind inaccessible)
- Equations without numbers
- Symbols used but never defined
- Inconsistent acronym usage
- References missing DOIs
- Duplicate references with different keys
